\# HealthConnect Infrastructure Capstone



\## Project Overview

Automated deployment of a secure, 3-tier VPC architecture on Google Cloud Platform using Terraform.



\## Technical Features

\- \*\*Logical Isolation:\*\* 3-tier subnets (Public, Private, Isolated)

\- \*\*Security:\*\* IAP-based SSH access and Cloud NAT for secure egress

\- \*\*IaC:\*\* Fully modularized Terraform configuration
